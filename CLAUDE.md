# CLAUDE.md

Homebrew tap for the `tbc` CLI. There is no application code here: `Casks/tbc.rb`
is generated by the CLI's release process ("DO NOT EDIT"), which also publishes
the release binaries to this repo.

**This repo is public.** Keep everything in it — README, this file, PR titles and
bodies, review replies — free of internal platform details: no component names,
architecture, file paths from other repos, or links to private repos.

@../conventions/core.md

### Deviations
- The README is install-only (the public-repo exception in the workspace README
  standard).
- Cask bumps come from the release process; don't hand-edit `Casks/tbc.rb`
  beyond minimal, mechanical fixes.
