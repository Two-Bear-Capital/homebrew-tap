# homebrew-tap

Homebrew tap for **`tbc`**, Two Bear Capital's internal command-line tool.

The tap is public so it installs without a GitHub token. Using `tbc` requires a
Two Bear Capital account.

## Install

Requires [Homebrew](https://brew.sh) on macOS or Linux:

```sh
brew install two-bear-capital/tap/tbc
tbc auth login
brew upgrade two-bear-capital/tap/tbc   # later
```
