# Contributing — homebrew-tap

This tap holds only the Homebrew cask definition (`Casks/tbc.rb`) — there is no
build or test stack.

## How the cask is updated

Cask version + asset URL + sha256 bumps are **published automatically** by
[`tbc-platform`](https://github.com/Two-Bear-Capital/tbc-platform)'s release
process (GoReleaser). **Prefer that flow over hand-editing** the file here
(`Casks/tbc.rb` even carries a "generated by GoReleaser. DO NOT EDIT" banner).

If you must edit by hand, keep changes minimal and mechanical (version, URL,
sha256), and verify with:

```sh
brew audit --cask --tap two-bear-capital/tap   # or install locally: brew install --cask ./Casks/tbc.rb
```

## Conventions

Follow the platform [`conventions/`](https://github.com/Two-Bear-Capital/tbc-platform-workspace/tree/main/conventions)
catalog where applicable (Conventional Commits). Branch off `main` and open a PR.
